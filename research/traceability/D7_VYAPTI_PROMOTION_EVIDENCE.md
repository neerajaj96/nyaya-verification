# D7 Vyāpti-Promotion Evidence — Observed Association → Valid Inference

Question: does the corpus support the sequence
observed-association → hetu → established-concomitance → vyāpti → valid
inference? The sequence is NOT assumed classical. Each transition is scored:
EXPLICIT (stated) / COMMENTARIAL (commentator's reading) / ENGINEERING (our
abstraction) / UNSUPPORTED.

## T1. Observed association → hetu (reason-status)

- NS stratum: EXPLICIT that hetu-status is EARNED, not observed. 2.1.38
  Bhāṣya: only QUALIFIED particulars (rain-augmented water, calm hosts,
  ṣaḍja scream) count as probans; vague generals do not. 1.2.7 Vārttika:
  non-finding counts only from admitted-by-both-parties loci.
- TS stratum: EXPLICIT pakṣadharmatā + vyāpti-qualification (§3).
- Verdict: T1 = EXPLICIT (both strata), with stratum-specific earning-rules.

## T2. Hetu → established concomitance

- NS stratum: COMMENTARIAL-to-EXPLICIT borderline. EXPLICIT locutions:
  "cannot be brought about by any other cause save rain"; "never found
  unconcomitant with coming rain" (2.1.38 Bhāṣya/Vārttika). But no
  concomitance-NAME, no universal quantifier, no procedure beyond exhibiting
  qualified cases + surviving the trilemma (1.1.5 Vārttika: cause-effect
  texture accepted).
- TS stratum: EXPLICIT four-component vyāptigraha (§7 D).
- Verdict: T2 = EXPLICIT-as-locution / COMMENTARIAL-as-procedure (NS);
  EXPLICIT (TS). The NS→TS gap (procedure codification) is Tier-2-shaped and
  unfilled (G-UD-01).

## T3. Established concomitance → vyāpti (term-status)

- NS strata: UNSUPPORTED — the term never occurs as definiendum; using
  "vyāpti" for NS concomitance-talk is OUR back-projection (ENGINEERING
  convenience, flagged each time).
- TS stratum: EXPLICIT (§4 mūla + guarded D definition).
- Verdict: T3 = UNSUPPORTED (NS) / EXPLICIT (TS). Stratum tags mandatory.

## T4. Vyāpti → valid inference

- NS stratum: EXPLICIT that qualified probans + exhibited concomitance
  yields "infallible inference" (2.1.38: serpents; foam/hosts/ṣaḍja), AND
  explicit that FAULTY attempts are user-error ("fault lies with the
  inferring person"). Five-factor display required (1.1.32).
- TS stratum: EXPLICIT parāmarśa→anumiti under pakṣatā (§§2–3) + five
  members (§9).
- Verdict: T4 = EXPLICIT (both), with different licensing conditions
  (NS: qualification + exhibition; TS: +pakṣatā + blocking-theory clearance).

## What the new material adds to D7

1. An NS promotion pattern with THREE sourced checks (qualification /
   no-other-cause / never-unconcomitant) — usable as an NS-mode promotion
   sketch WITHOUT importing TS's tarka/sāmānya (which remain TS-only).
2. A sourced REJECTION pattern (mention-then-reject with reasons, 2.2.1
   Vārttika purposes) for failed candidates — the "correct" half of any
   generate-verify-correct loop, if one is ever built.
3. A hard boundary: NOTHING mined, NOTHING universalized beyond exhibits,
   NOTHING resembling support/confidence in either stratum — frequency-only
   induction fails NS-mode (2.1.37) and TS-mode (vajra) alike.
4. The missing comparator (trairūpya, G-DG-01) blocks adopting ANY
   occurrence-discipline (sapakṣa-presence/vipakṣa-absence) as "the"
   promotion rule — both NS sapakṣa-talk and TS vipakṣa-talk are
   school-internal until Buddhist discipline is sourced.
