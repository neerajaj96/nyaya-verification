## Status semantics

- "TS-mode only (= baseline shape)" = the baseline implements the TS column
  whether or not it says so; NS columns need new (unwritten) code.
- "DEFERRED" = no specification permitted yet (see DEFERRED_DECISIONS.md).
- "NOT_ACQUIRED" in Buddhist/Navya-Nyāya columns is a GAP MARKER, never a
  claim of absence in those traditions.
